Providers

Save a key on each provider you use. Pick the provider and model in the bar at the bottom of the window when you generate text or images. Keys are stored only in this browser's localStorage and are sent directly to the provider you choose — this app has no server of its own.

    Provider

    Browser CORS extension required for OpenCode. opencode.ai omits Access-Control-Allow-Origin on inference POST routes. Model discovery via GET /models works without an extension.
    Off requests no thinking; models that cannot disable reasoning use their default. Higher levels spend more reasoning tokens before the page streams.
    Used only for the site plan, generated once per domain and era. Homepage and child pages use Reasoning Effort above.

    Dream

    🏛️ Grounded 🌌 Alternate History
    100% anchored to real-world history, real companies, real events, and authentic facts of the selected date.
    Pixel, SVG, era-adaptive, and hybrid ad/icon art use the text provider and model. A dedicated image model and hybrid photos use the Image pair in the bar below.

    Running in a browser tab. Use Install on the toolbar when the browser offers it.
